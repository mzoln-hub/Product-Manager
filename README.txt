Simple Product Manager

Description:
A simple Flask web application that allows users to add, view, search, and delete products. Product data is stored in a SQLite database using Flask-SQLAlchemy.

Requirements:
•	Python 3.x
•	Flask
•	Flask-SQLAlchemy

Setup Commands:
1.	Create a virtual environment:
python -m venv .venv
2.	Activate the virtual environment:
..venv\Scripts\Activate.ps1
3.	Install dependencies:
pip install -r requirements.txt

Run Command:
python app.py

Features:
•	View all products
•	Add new products
•	Delete products
•	Search products by name or category
•	Input validation
•	SQLite database storage
